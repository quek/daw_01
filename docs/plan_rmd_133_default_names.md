# r.md #133 トラック・シーンの既定名を数字だけに

索引: [plan_rmd_130_133_index.md](plan_rmd_130_133_index.md) (分担・統合順・共通規則)。
調査: `scratchpad/rep/133-default-names.md` (コード地図、生成箇所と表示箇所の全列挙) / `r133.md` (Live / Bitwig / REAPER / Cubase / Studio One / FL / Logic)。

## 理想

既定名は**「名前を持たない」状態として保存** (空文字) し、表示名は **1 つの関数**が並び順から数字を作る。並べ替え・削除に番号が追従し、
全表示箇所 (ヘッダ / ミキサー / インスペクタ / send 先 / 各種 dropdown / 窓タイトル / 変調ラベル) がその関数を通る
(今は `Track {位置+1}` / `Track {id}` / `→{id}` / 空欄 が混在している、調査 §5)。改名で空を確定すると自動名に戻る
(シーンの既存契約 `handler/launcher.rs:1067` と同じ)。シーンも同じ仕組みのまま表示を数字だけにする。
Ableton (Live 11 のシーン)・Bitwig・REAPER・FL と同じ「空で保存・位置から表示」方式。

## 確定仕様 (2026-09-15 ユーザー承認)

| # | 論点 | 決定 |
|---|---|---|
| Q1 | 番号の振り方 | **上から順の通し番号**。グループもリターンも 1 本として数え、グループの子も続きの番号 (例: `1` / `2 (グループ)` / `3` / `4` / `5`) |
| Q2 | 既存プロジェクトの `Track 3` 等 | **そのまま残す** (ユーザーが付けた名前と区別できないので書き換えない。開いただけで `*` にしない)。数字の自動名になるのは新しく作るトラックだけ |

### main が決めた細部 (ユーザーに報告済み)
- **対象**: 今 `Track N` / `Group N` / `Return N` を焼き込んでいる全生成経路 (調査 §1: トラック追加 / 新規プロジェクト・タブ /
  0 本時の自動補充 / 余白への移動・コピー・別タブ drop / グループ化 / リターン追加) → 空名で作る。
  **ファイル等の由来名は変えない** (audio / MIDI / video / image import、`Capture_…` / `Sampler_…`、`(FX)`)。
- **パラアウト展開** (`{元トラック名} Out {n}`、`devices.rs:787,815`): 元が未命名なら元の表示名 (その時点の番号) を使って焼く
  (説明的な派生名であり、既定名ではない)。
- **複製**: 未命名のトラックは未命名のまま複製される (= 新しい位置の番号で表示)。名前付きは今どおりコピー。
- **改名**: 入力欄の初期値は表示名。空、または自動名と同じ文字列で確定すると未命名に戻る (シーンと同じ)。
  トラック改名の「空確定は無視」(`tracks.rs:1219`) はこの契約に置き換える。
- **番号の数え方**: アレンジに表示される上からの順。折りたたんだグループの子も数える (折りたたみで番号を変えない)。
  マスターは `Master` のまま。削除済みトラックを指す表示 (今は `Track {id}`) は、表示名関数の中で 1 つの文言にそろえる。
- **シーン**: `Scene::display_name` (`common/src/model/session.rs:51-57`) を `N` にする。インスペクタの「列「…」のフォローアクション」等は
  同関数を通るので自動で `列「3」` になる。テスト `session.rs:943-949` を更新。
- **Parallel の chain 名 (`Chain N`) / Arranger セクション名 (Intro / Aメロ …) / 内蔵デバイス名**は対象外 (トラックでもシーンでもない)。
- 版番号: 新しい field は増えない。**旧ビルドで開くと未命名トラックのヘッダが空欄になる**だけで壊れはしないが、gate が要ると判断したら
  **v42** (索引の事前割当) を使い、判断を報告に書く。

## 設計

- **表示名の SSoT**: common に `Song` のメソッド (例: `track_display_name(track_id) -> Cow<str>` と、位置が既知のときの版) を 1 つ置く。
  `daw_gui/src/handler/view_model.rs` の `track_display_name` (`:473-483`)・`selected_track_label` (`:301-`)・ミキサー (`:278-282`)・
  インスペクタ見出し (`:315-321`)・send 先候補 (`:61-65`)・変調ソース候補 (`:407`) と、調査 §5 の表の**全行**をこれへ寄せる
  (口パク出力先 `lipsync.rs:39-43` の `Track {id}`、ミキサーの send 行 `mixer_strips.rs:906-909` の `→{id}`、サイドチェイン / follower /
  パラアウト宛先 `handler/parallel.rs:621,644` の `{name} (id {id})`、プラグイン窓タイトル `devices.rs:630`、ピアノロール行ラベル、仮想鍵盤、
  リソースモニタ、ロック通知、Sampler のソース候補とファイル名)。
- 数字だけの名前が id と並ぶ表示 (`3 (id 7)`) は紛らわしいので、id を併記している箇所はその必要性を見直す (同名区別が目的なら位置番号で足りる)。
- ヘッダの描画 (`widgets/arrangement/header.rs:392`、キャッシュ `view_model.rs:1094-1097`) も表示名関数から。
- 生成経路は空名で作る。`Return N` の番号計算 (`mixer.rs:399-410`) や総数 + 1 の計算は不要になるので消す。
- 文書: `docs/plan_group_track.md:120`、`docs/plan_rmd_87_clip_launcher.md:59,263`、コード内コメント (`event.rs:1102`、`mixer.rs:393`、
  `mixer_strips.rs:914`、`launcher.rs:1048,1054`、`launch_section.rs:126`、`devices.rs:188`) を実装に合わせる。

## テスト (高いレイヤーで)
- トラック追加 → 名前は空・表示は位置番号 / 並べ替え・削除で表示番号が追従 / グループ化・リターン追加も空名。
- 改名: 空確定・自動名と同じ文字列の確定で未命名に戻る。
- 未命名トラックの複製が未命名。既存の `Track 3` という名前は load 後もそのまま (開いただけで dirty にならない)。
- シーンの表示名が数字。
