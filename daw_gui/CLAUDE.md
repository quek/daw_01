# daw_gui

共通の規範は root の [CLAUDE.md](../CLAUDE.md)、daw-ui の使い方と罠は [ui/CLAUDE.md](../ui/CLAUDE.md)。
ここには daw_gui の view を足す・変えるときの配置と操作性だけを書く。

## UI の配置・操作性

機能を view に挿す前に描画コードを読み、**どこに・どう出るか / 開閉で何が動くか / どこと重複するか** を
確かめる (推測で y を動かさない)。配置・色・コントラストは build / clippy / test をすり抜けるので、実機で
目視する。

- **配置 = トリガの近く**: パネル / セクションは、それを開閉するボタンの近くに出す。トリガ (例: チェーン行の
  「Par」ボタン) と表示 (例: インスペクタ最上部) が離れると、押しても効いたか分からない。
- **開閉で他のコントロールを動かさない (特にトリガ自身)**: インスペクタ
  (`daw_gui/src/view/track_inspector/mod.rs`) は title 下の全部が 1 本の縦 scroll viewport で、各セクションを
  `(app, ui, area, pad, y) -> f32` の関数で上から積む (y カーソル 1 本、並び順がそのまま画面の上下順)。
  トリガより上で高さが変わると、トリガごと下にずれて「押した瞬間ボタンが逃げる / 表示してすぐ非表示」になる
  (2026-06-20 実例)。開閉するパネルはトリガの直下 (行内アコーディオン) に出す。
- **縦 scroll の制約**: content 高には前フレームの測定値 (`inspector_body_h`、immediate-mode の lag-by-one) を
  使う。背の高いパネルもこの流れの中に積む。
- **同じ param の編集面を 2 箇所に作らない**: 既存の専用セクションと新パネルの二重表示をしない。表示面は 1 つに
  集約し、もう片方は gate で隠す (2026-06-20 に字幕 X/Y・talk 話速で手戻り)。
- **既存の idiom を使う**: `scrubable_number` / `dropdown` / video_fx param パネル
  (`inspector_video_fx_params`) / clip voice picker。bespoke な edit-buffer widget を新設しない。
- **可変背景 (クリップ色 / トラック色 / 波形) の上の標識はコントラストを保証する**: 固定の白 / 黒 単色は
  明クリップ上・暗クリップ上のどちらかで沈む。暗い半透明チップ + 明色標識 (idiom:
  `voicevox_overlay::draw_spinner_badge`) / 対比色の輪郭 / 背景輝度からの auto-contrast のいずれかにし、
  明るいクリップと暗いクリップの両方で目視する (`track_color` の明色プリセットで 1 つ着色する)。
- **「上 / 下 / 近く / 見づらい」等の配置の指摘**は、どのセクション関数のどの `y` に出ているかを特定してから直す。
